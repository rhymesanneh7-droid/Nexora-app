NEXORA INVESTMENTS — PHONE-READY WORKING PROTOTYPE

This is a self-contained Progressive Web App (PWA).
It includes working navigation, demo investment flow, portfolio, learning,
notifications, profile, buttons, an installable web-app manifest, and offline caching.

IMPORTANT:
This is an educational/school-project simulation. It does not process real investments,
payments, bank details, or financial transactions.

To install on iPhone:
1. Publish these files at an HTTPS web address.
2. Open the address in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Turn on Open as Web App, then tap Add.
